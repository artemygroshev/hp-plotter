# Границы проверки публикации

Дата подготовки: 2026-11-07.

Исходная лабораторная версия прошла 95 офлайн-проверок и полный аппаратный сеанс: 72 последовательных запроса, три полных LCD-буфера, 30/30 выбранных полей. Каждый native-буфер заново собран из исходных адресованных ответов; PNG соответствует всем пикселям. Устройство и его интерфейс/очередь проверены до и после запросов. История сеансов с идентификаторами установки остаётся приватной.

В опубликованной копии изменена обвязка конфигурации/SSH: локальные идентификаторы заменены шаблоном, учётные данные не встроены, дедлайн задаётся явно, устаревшие фиксированные адреса аллокаций убраны из словаря, recovery не доступно через переносимый runner. Эта копия проверяется офлайн; повторный аппаратный сеанс именно переносимой обвязки не заявляется.

Тестовый набор публикации: 76 service/config-тестов и 22 firmware/access-теста. При наличии двух отдельно полученных официальных firmware выполняются все 98 проверок; без firmware один интеграционный тест регистрации команд пропускается явно. Ключевые проверки: неверный адресат/ID, частичный OUT без повтора, восстановление при исключениях, отсутствие padding, лишние/дублированные байты, nonce, геометрия и ориентация, фазы мигания, отсутствие конфигурации и права приватного password-файла.

C-экстрактор собран с `-Wall -Wextra` против отдельно установленной libmspack; проверен отказ принимать не-CAB без создания результата. Свежая выборка файлов проверена на реальные закрытые идентификаторы/пароль исходной установки, типичные форматы токенов/ключей и локальные ссылки Markdown. Эти проверки уменьшают риск ошибки комплектации, но не заменяют проверку пользователем собственных будущих добавлений.

В публичной истории должны находиться только явно отобранные исходники, документация, шаблон и LCD-примеры. Образы HP/Windows, локальный JSON, private password-файлы, known_hosts, ключи, журналы и vendored-зависимости исключены. Первоначальная рабочая копия проекта сохранена отдельно и её исходники сверены по SHA256 после подготовки публикации.
