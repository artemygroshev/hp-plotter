# Документация HP Plotter Lab

Проект соединяет **HP DesignJet 500 C7769B / A.04.02** и Linux-плату BTT/CB1
через USB–parallel. Печать и служебное чтение используют один переходник;
локальная служба публикует проверенные LCD/статусы для браузера.

## Выбрать порядок

1. Начните с [результатов](validation.md): совместимость относится к конкретной прошивке и мосту.
2. Подготовьте плату по [BTT/CUPS](btt.md) и [разовый клиент](quickstart.md).
3. Для постоянного просмотра установите [локальную службу](monitor.md).
4. Проблемы картинки разбирайте по [печатному потоку](raster.md), отдельно от состояния головок и физического отпечатка.
