# BTT/CB1 и очередь печати

Исследована Linux-плата BTT/CB1 с Wi-Fi и отдельным USB–parallel мостом 1a86:7584. Установка Klipper не мешает использовать Linux/CUPS; для этого не требуется прошивать плату заново. Сохраняйте существующие службы и конфигурации. Питание платы в лаборатории было отдельным; непроверенное питание от внутренних линий плоттера здесь не предлагается.

## Зависимости платы

На Debian/Armbian требуются CUPS, `ipptool`, Ghostscript с устройством `cdnj500`, Foomatic и libusb. Имена пакетов для Debian: `cups cups-ipp-utils cups-filters foomatic-db-compressed-ppds ghostscript libusb-1.0-0 python3`. Проверяйте доступность в своей версии дистрибутива. При отсутствии интернета пакеты нужно получать из подписанного репозитория для архитектуры/версии платы; не переносить случайный rootfs или настройки другой BTT.

Проверки на плате:

```bash
gs -h | rg cdnj500
lpinfo -m | rg -i 'designjet.*500|cdnj500'
lpinfo -v
systemctl is-active cups
```

При исправном обнаружении выберите модель cdnj500 для DesignJet 500 и фактический URI из `lpinfo -v`. Например, с **заменёнными** шаблонами:

```bash
sudo lpadmin -p HP-DesignJet-500 -E -v 'YOUR_DETECTED_USB_URI' -m 'YOUR_CDNJ500_MODEL_ID'
sudo lpadmin -p HP-DesignJet-500 -o printer-is-shared=true
```

Настройку сетевого доступа CUPS выполняйте для своей доверенной локальной сети. Не публикуйте службу печати в интернет. IPP URI клиента имеет вид `ipp://BTT_ADDRESS:631/printers/HP-DesignJet-500`. Настоящий адрес и параметры Wi-Fi задаются локально, в репозитории их нет.

На исследованном мосте ID мог портиться и менять обнаруженный USB URI. Обновление URI помогает очереди найти устройство, но само по себе не исправляет мост. Сверяйте модель/ID и не считайте разовый URI постоянным. Применение глобальных USB quirks или отключение обратного канала не является частью установки.

## Рулон 610 мм

Для C7769B использовался номинальный рулон 610 мм. В локальной PPD предел Custom Width был приведён к 610 мм = 1729,1339 points: поля `MaxMediaWidth` и `ParamCustomPageSize Width`. Предел высоты и остальные возможности берутся из исходной PPD. Получайте PPD из OpenPrinting/пакета дистрибутива с сохранением её лицензии; в репозитории чужая PPD не распространяется.

После сохранения проверенной локальной PPD её можно назначить существующей очереди: `sudo lpadmin -p HP-DesignJet-500 -P /path/to/local-610mm.ppd`. Сверьте строки `*MaxMediaWidth: 1729.1339` и `*ParamCustomPageSize Width: 1 points 36 1729.1339`; не меняйте одновременно драйвер, носитель и транспорт при сравнительном опыте.

Перед внешней проверкой сравните входной PDF, результат RIP и выбранные настройки. Пример параметров одной страницы: `Custom.610x100mm`, `RollPaperCut`, `Quality=normal`, `copies=1`, `print-scaling=none`. Тип носителя на панели должен соответствовать реальной бумаге; команда задания может не переопределять MEDIATYPE.

Программное `completed` означает завершение CUPS, но не подтверждает качество бумаги. После ошибки головки сначала требуется её диагностика. Основной LCD-клиент не отправляет проверочные страницы и не запускает встроенный Troubleshooting.

## Совместимость и границы

USB-мост объявлял alt0 unidirectional и alt1 bidirectional, Bulk OUT 0x01 / IN 0x82, пакет 64 байта. Исследованный usblp при detach менял alternate; библиотека проверяет/восстанавливает его. USB GET_INTERFACE и host sysfs могли расходиться, поэтому один control-ответ не считается достаточным.

Для чтения экрана JetDirect не нужен. Ethernet-карта остаётся альтернативным трактом печати; исправление старых артефактов таким переходом не проверено. Совместимость конкретной EIO-карты нужно проверять отдельно до покупки.
